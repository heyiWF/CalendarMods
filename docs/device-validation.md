# 设备验收

验收对象：`mycompat` 分支的单页版式（**今朝 · 每日一页**），含深色模式与 12 / 24 小时制。

## 构建与设备

- 构建命令：`testDebugUnitTest assembleDebug assembleDebugAndroidTest lintDebug --offline`。
- 52 个 JVM 单元测试通过，0 失败：历法、日期行节气/节日拼接、分页、字号缩放边界、配色对比度、夜间窗口、光线迟滞、12 / 24 小时读数与人脸相关规则。
- Lint：`No issues found.`
- ADB 设备：`emulator-5554`，Android 15 / API 35，1440 × 2560，density 360，字体缩放 1.0。

## 页面渲染

- `CompatAcceptance` 用例在设备上逐张渲染 **竖屏 360 × 640** 与 **横屏 640 × 360** × **85% / 100% / 140%** 字号 × **浅色 / 深色** 两种印法，共 12 张，另有 24 小时制与 12 小时制各一张，全部 PASS。
- 每张渲染图检查四件事：整页确实印出了内容（非纸色像素 > 千分之五）；**画面最底三行像素必须是纸色**，即所有内容都落在屏幕内；**最右八列在日期行高度内必须是纸色**，即日期行收在右边界以内；左上角像素必须是所选印法的纸色，确保整页铺满。
- 人工核对：日期行（“11月 7 日 星期六 九月廿九立冬”）**同一字号、同一基线**，五段之间的空隙在 85% / 100% / 140% 下都保持可见，农历始终占着自己的位置；节气直接接在农历后面、中间无空格；时钟冒号抬到数字垂直中线；时钟、六行七列月历、左下角宜忌在深浅两套配色下都清晰可读；横屏日期行与分隔线贯穿全宽，月历整体下移并贴住屏幕下沿。
- 12 小时制在设备上读作 `上午1:30`：「上午」与数字同字号，冒号同样居中，整行收在列宽内；24 小时制仍是 `01:30`。
- 11/07 立冬当天，日期行读作 `11月7日 星期六 九月廿九立冬`，节气紧接农历、中间无空格；140% 字号下整行按比例收缩，五段仍各自成段、互不重叠，右端留有一格左右的余量。
- 滚动轮播在 11/07（立冬）与 11/22（小雪）等日期上确认：农历与节气/节日每 3 秒上滑切换，同一行的格子同步。

## 样式面板

- 字号滑块读数与存储值双向一致；拉到 85% / 140% 时整页仍完整落在屏幕内，每一块都读得清。
- 「24小时制」开关默认开启，点击后样式立即切到 12 小时制并回写 `hour24`，再点一次恢复；预览页右上角的时间戳与全屏时钟同步变化。
- 深色模式各选项互斥，选中项与存储值一致；选中「定时切换」后「深色开始 / 深色结束」两条滑块才出现，切回固定来源时隐藏，面板高度随之重新测量。
- 「跟随环境光」在带光线传感器的设备上出现，选中后按环境照度切换。
- 翻页动画、人脸感应亮屏（带摄像头的设备）、交互式日历各开关与验收脚本原有断言一致。
- 每个开关／选项的辅助说明只留一句、不超过 15 字，单行显示不换行；面板展开后仍完整落在 82% 屏高之内，末行「完成」不被遮挡。

## 深色模式

- 强制「始终深色」后，窗口底色、预览页、全屏页同时换页；切回「关闭」后恢复浅色，均无需重启。
- 「定时切换」把窗口设为 13:00 – 15:00、设备时间为 01:11 时，页面保持浅色；窗口设为默认 19:00 – 07:00 时为深色，说明本地小时判定与持久化都正常。
- 「跟随环境光」在模拟器上可选并保持深色（模拟器光线读数处于暗区）；逻辑本身由 `LuxDarkGateTest` 覆盖阈值、迟滞与确认窗口。
- 偏好在 `theme_styles` 中持久化：`dark_mode`、`dark_from`、`dark_to`、`hour24` 与字号、开关一并保存。

## 交互

- 单击进入全屏、长按或返回键退回预览；进入途中按返回可反向收回，预览与全屏页衔接不跳位。
- 只有单击才进入全屏，滑动与误触保持原位；开启交互式日历后左右滑动切换日期，离开今天时出现“回到今天”。
- 前台跨过午夜自动换日并播放翻页动画；从后台返回时直接同步到当天。
- 验收后恢复屏幕方向与自动旋转设置，清空应用数据回到默认样式。

## 复现

```bash
./gradlew :app:testDebugUnitTest :app:lintDebug --offline
./gradlew :app:assembleDebug :app:assembleDebugAndroidTest --offline
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb shell am instrument -w com.calendarmods.test/com.calendarmods.CompatAcceptance
```

验收渲染图会写入设备的 `Android/data/com.calendarmods/files/acceptance/`，可用 `adb pull` 取回逐张核对。
