# 页面版式与数据来源

「今朝 · 每日一页」是应用唯一的内置版式，全部由 `DailyPage` 用 Canvas 绘制，没有任何图片资源。

## 设计坐标

| 方向 | 设计尺寸 | 版式 |
| --- | --- | --- |
| 竖屏 | 360 × 600 | 单列：日期行 / 时钟 / 宜忌 / 月历 |
| 横屏 | 640 × 360 | 双列：左列日期行、时钟、宜忌，右列月历 |

所有坐标都是设计坐标，`PaperView` 按 `unit = 实际尺寸 / 设计尺寸` 缩放后在真实像素上绘制，所以同一套常量在小屏和大屏上比例一致。

## 版式规则

- **一条左线、一条右线**：日期行、时钟、宜忌、月历共用 `margin`（竖屏 26、横屏 28）作为左右边界，逐块左对齐。
- **日期行**：`11月` 20 号 + 日号 42 号衬线粗体 + `日` 20 号 + `星期五` 16 号，右侧以同一条基线右对齐当天农历（15 号、次要色）。日号刻意比前后文字更大更重，作为整页的第一视觉落点。
- **时钟**：64 号细字重，字距 1.2，紧贴日期行下方的分隔线。
- **宜 / 忌**：先按当天条目测出两块的实际高度，再把剩余高度三等分作为上下与中间的间距（上限 90；空间不足时固定 10），避免“忌”下方留下空洞。条目按全角空格分隔自动换行，放不下时逐级缩小字号，保证条目不被截断。某一侧没有条目时印「诸事不宜」或「诸事皆宜」。
- **月历**：固定六行七列，周一在前、周日在后。`cellH = min(可用高度 / 6, cellW × 1.04)`，日号 40% 格高、农历标签 17% 格高。周末（周六、周日）用红色；今天画实心底圆并反白；非本月日期降到 40% 不透明度。每格下方标签的高度单独留出并用 `clipRect` 裁剪，轮播时文字不会溢出到相邻行。

## 轮播时间轴

带节气或节日的日期，其标签在农历与节日名之间循环上滑：

| 常量 | 值 | 含义 |
| --- | --- | --- |
| `HOLD_MS` | 3000 | 每个字段的静止停留时间 |
| `TRANSITION_MS` | 240 | 上滑过渡时长 |
| `CYCLE_MS` | 3240 | 一轮的完整周期 |

相位取自 `SystemClock.uptimeMillis()`，全页共用一个时间轴，因此同一行的所有单元格同时翻页。过渡时旧文字自 `y` 上移到 `y - h`，新文字同步自 `y + h` 上移到 `y`，形成一整格上滑的手感。

`DailyPage.frameDelay(now)` 给出下一次画面可能变化的时间：停留期取相位剩余时间，过渡期取一帧（16 ms）。`PaperView` 再与“下一个整分钟”（时钟）取最小值调度重绘，因此页面在停留期只有极少的重绘，而不是每帧重画。

静态场景（预览卡片、系统截图式的渲染）把 `motion` 置为 `false`、`now` 置为 `0`，直接印出第一个字段，动画偏好为 0 时同样走这条路径。

## 数据来源

历法与宜忌由 `tyme4j`（`com.tyme.solar.SolarDay`）计算，全部在本地完成：

| 需求 | 取值 |
| --- | --- |
| 农历月名 / 日名 | `lunarDay.lunarMonth.name`、`lunarDay.name` |
| 节气 | `termDay`，仅当 `dayIndex == 0` 才算当天 |
| 农历节日、公历节日 | `lunarDay.festival`、`festival` |
| 数九、三伏 | `nineDay`、`dogDay`，同样只取 `dayIndex == 0` |
| 宜、忌 | `lunarDay.recommends`、`lunarDay.avoids` |

节气只在节气当天标注，不会在半个月里天天出现；同一天的多个节日（例如中秋与国庆）全部保留并按顺序轮播。

## 缓存与刷新

- **按日缓存 8 条** `CalendarData`：旋转屏幕、切后台回来、恢复前台都直接命中，不再重算。
- **按月缓存 4 份月历网格**：跨午夜时只换当天数据，六行七列的 42 格复用上一次的结果。
- **凌晨对齐**：`PaperView` 用 `System.currentTimeMillis() % 60_000` 安排下一次重绘，时钟跳分钟、跨过午夜换日都不依赖轮询。

日期本身由 `PlainDate` 表达（无时区日期值类型，兼容 API 14），时区只在 `CalendarClock` 里出现一次。
