# 页面版式与数据来源

「今朝 · 每日一页」是应用唯一的内置版式，全部由 `DailyPage` 用 Canvas 绘制，文字取系统默认的无衬线字族。

## 设计坐标

| 方向 | 设计尺寸 | 版式 |
| --- | --- | --- |
| 竖屏 | 360 × 600 | 单列：日期行 / 时钟 / 月历 / 宜忌（左下） |
| 横屏 | 640 × 360 | 通栏日期行 / 左列时钟与宜忌 / 右列月历 |

所有坐标都是设计坐标，`PaperView` 按 `unit = 实际尺寸 / 设计尺寸` 缩放后在真实像素上绘制，所以同一套常量在小屏和大屏上比例一致。

## 版式规则

- **贴边**：整页 `EDGE = 14`，只有旧模板的一半左右，省下的空间全部给字号。
- **全部加粗、全部无衬线**：整页只用系统默认的无衬线字族（`sans-serif`，API 14 上即 Droid Sans，现代设备上是 Roboto），日期行、时钟、月历数字与农历、宜忌条目一律取其中的粗体，数字与标点也来自同一字族。
- **日期行**：`11月`、日号、`日`、`星期六` 与右侧农历**共享同一个字号 46 号**，同一基线；行内间距按 em 计（`.12 / .05 / .30 / .34`），所以整行缩小时字与空隙一起收，农历始终占着自己的位置。整行宽度先量一遍，超出时按比例收缩——收缩不设下限：右侧那一段可能连着节气或节日（最长是 `十一月三十` 再加三字节日，共九字），让星期与农历分得开优先于保住字号。横屏 640 宽通常不触发收缩。
- **右侧一段连排节气 / 节日**：`CalendarData.lunarHeadline` 把当天的节气或节日直接接在农历后面，中间不加空格，与整行同字号、同基线、一次印到底。优先级是节气 > 节日 > 无：当天交节印 `九月廿九立冬`；同一天既有节气又有节日（如 12 月 22 日的冬至与冬至节）印节气；没有节气而有多个节日时印数据源给出的第一个（中秋与国庆同一天印 `八月十五中秋节`）。这一段是单一字段，不轮播。三字节日（元宵节、端午节、重阳节、腊八节等）同样连排，最长的一行是腊八节落在腊月初八时的 `十二月初八腊八节`（八字）；设备验收脚本逐个量过这些日子，星期一段的右端始终停在这一段的左端之前。
- **时钟**：竖屏 64 号、横屏按左列宽度自动放大（上限约 1.5 倍），字距为字号的 1.6%。冒号单独一行基线，用 `Plate.centerShift` 量出数字与冒号的墨迹中心差，把冒号抬到数字的垂直中线。
- **12 / 24 小时制**：`ClockFace(period, hour, minute)` 把读数拆成三段，24 小时制 `period` 为空、小时补零（`01:05`）；12 小时制 `period` 为 `上午 / 下午`、小时不补零（`上午9:05`、`下午12:30`）。`上午 / 下午` 与数字同字号，整段宽度按列宽收缩（`fitClock`），因此 12 小时制整行都收在列宽之内。
- **横屏通栏**：日期行与分隔线贯穿整个屏幕宽度，月历排在通栏线下方、贴住屏幕下沿，视觉上整体下移。横屏只保留日期行下这一条通栏分隔线，月历星期行上方的浅横线只在竖屏出现。
- **月历**：固定六行七列，周一在前、周日在后。日号占格高的 62%，农历标签另占 30%；周末日号用红色，今天实心底圆反白，非本月日期降到 26% 不透明度。农历与日号同色（浅色页近黑、深色页米白），节气与节日由同一标签轮播呈现。三个字以上的标签完整显示：先缩到格宽，缩到七成仍放不下才横向走马灯，见[字段比格子宽时](#字段比格子宽时)。
- **宜 / 忌**：整块贴在屏幕左下角。「宜」是绿色圆角块内白色「宜」字，条目用绿色；「忌」是红色圆角块内白色「忌」字，条目用红色。条目按全角空格分隔自动换行；某一侧条目为空时印「诸事不宜」或「诸事皆宜」。

## 两套印法

同一份版式有两种配色：纸张黄的浅色页与深色纸页。配色以 `PageScheme` 传入 `DailyPage`，切换时不重新排版：

| Token | 浅色 | 深色 |
| --- | --- | --- |
| 纸面 `paper` | `#F7EBCE` | `#1B1913` |
| 正文 `ink` | `#14110C` | `#F3EAD4` |
| 忌、周末 `accent` | `#B3362B` | `#E1715C` |
| 宜 `herb` | `#2E6F3E` | `#7CC08D` |
| 色块内文字 `onAccent` | `#F7EBCE` | `#14120C` |

深色页沿用同一套层级：数字最重、农历次之、非本月日期降到 26% 不透明度。色块在深色页改为浅色填充 + 深色字，保证在暗色纸面上依然清晰。什么时候切换到深色页，见 [深色模式](dark-mode.md)。

## 字号调节

样式面板的「字号」滑块把整页按 **85% – 140%** 缩放，默认 100%。缩放不是简单乘系数，`DailyPage` 会先按目标字号算一遍版式，不满足下面任一条就按 2% 递减重算，直到满足或触底（70%）：

| 保护条件 | 含义 |
| --- | --- |
| 日期行 `headerFit` | 整行宽度 + 农历宽度 ≤ 版心宽度（不设字号下限，优先级高于字号） |
| 月历 `cellH ≥ 26` | 六行格子保持可读高度 |
| 宜忌 `almanacY ≥ 时钟底 + 6` | 宜忌块与时钟之间留出空隙 |
| 月历数字 `fitNumber` | 数字宽度 ≤ 格宽 92%，高度 ≤ 标签以上剩余高度 |
| 农历标签 `min(cellH × 30%, cellW × 46%)` | 两个字一定落在格内 |
| 宜忌占比上限 | 竖屏 ≤ 页高 26%、横屏 ≤ 46%，超出时只缩宜忌条目，月历保持原尺寸 |

因此滑块拉到两端时，页面呈现的是“月历略紧、宜忌略小”，整页仍完整落在屏幕内，每一块都读得清。设备验收在 85% / 100% / 140% 三种字号、横竖两个方向、深浅两种印法下逐张贴图渲染，检查屏幕最底三行像素仍是纸色（内容全部落在屏幕内）、最右八列在日期行高度内仍是纸色（日期行收在右边界以内）；另外用 `headerSpan` 直接量星期段与农历段的边界，把三字节日与九字最坏情况在六个组合下逐个对账，确认两段始终不相遇。

## 轮播时间轴

带节气或节日的日期，其标签在农历与节日名之间循环上滑：

| 常量 | 值 | 含义 |
| --- | --- | --- |
| `HOLD_MS` | 3000 | 每个字段的静止停留时间 |
| `TRANSITION_MS` | 240 | 上滑过渡时长 |
| `CYCLE_MS` | 3240 | 一轮的完整周期 |

相位取自 `SystemClock.uptimeMillis()`，全页共用一个时间轴，因此同一行的所有单元格同时翻页。过渡时旧文字自 `y` 上移到 `y - h`，新文字同步自 `y + h` 上移到 `y`。

`DailyPage.frameDelay(now)` 给出下一次画面可能变化的时间：停留期取相位剩余时间，过渡期取一帧（16 ms）。`PaperView` 再与“下一个整分钟”（时钟）取最小值调度重绘，因此停留期几乎不重绘。

静态场景（预览卡片、验收渲染）把 `motion` 置为 `false`、`now` 置为 `0`，直接印出第一个字段；动画偏好为 0 时同样走这条路径。

## 字段比格子宽时

格子只有约 47 设计单位宽，两字以内摆得下，三个字会溢出约 36%。这里按两级处理（`LabelMarquee`），每个标签都完整印出：

| 情况 | 处理 |
| --- | --- |
| 两字以内 | 居中直排，不缩放 |
| 三字 | 整体缩到格宽（约七成），一次印完整 |
| 四字及以上 | 缩到七成仍读不清，改横向走马灯 |

走马灯的节奏：

| 常量 | 值 | 含义 |
| --- | --- | --- |
| `STATIC_CHARS` | 2 | 两字以内一律直排 |
| `MIN_FIT` | 0.62 | 缩小后低于字号 62% 就不缩了，改走字 |
| `PAUSE_MS` | 1000 | 走之前先停一拍，先读开头 |
| `SPEED` | 40 | 每秒 40 设计单位（360 宽的页面约 11% 屏宽/秒） |
| `FRAME_MS` | 16 | 走字期间逐帧重绘 |

字段自格子左沿起排，等 `PAUSE_MS` 后按溢出距离匀速左移，走到最后一字完全进入格子即停住，剩余停留时间里保持静止；下一轮轮播时重新开始。三字标签按格宽缩小一次印完整：格子只容得下约 2.2 个字，缩到七成仍读得清，比滚动更稳。

`DailyPage.labelDelay` 记录当前帧里走马灯的下一帧间隔，`PaperView` 在 `onDraw` 结束后据此调度重绘：只有正在走字的字段才逐帧重绘，静止时仍按整分钟／轮播边界唤醒。

`Plate.text` 只按可用高度缩字号，全页任何位置的字段都完整印出。


## 数据来源

历法与宜忌由 `tyme4j`（`com.tyme.solar.SolarDay`）计算，全部在本地完成：

| 需求 | 取值 |
| --- | --- |
| 农历月名 / 日名 | `lunarDay.lunarMonth.name`、`lunarDay.name` |
| 节气 | `termDay`，仅当 `dayIndex == 0` 才算当天 |
| 农历节日、公历节日 | `lunarDay.festival`、`festival` |
| 数九、三伏 | `nineDay`、`dogDay`，同样只取 `dayIndex == 0` |
| 宜、忌 | `lunarDay.recommends`、`lunarDay.avoids` |

节气只在节气当天标注。同一天的多个节日（例如中秋与国庆）在月历标签里按顺序轮播；日期行取其中一个，顺序与 `CalendarData.festivals` 一致。数九、三伏标记的是一段时令而非某个节日，它们参与月历轮播，日期行只接节气与节日。

## 缓存与刷新

- **按日缓存 8 条** `CalendarData`：旋转屏幕、切后台回来、恢复前台都直接命中。
- **按月缓存 4 份月历网格**：跨午夜时只换当天数据，六行七列的 42 格复用上一次的结果。
- **整分对齐**：`PaperView` 用 `System.currentTimeMillis() % 60_000` 安排下一次重绘，时钟跳分钟、跨过午夜换日都不依赖轮询。

日期本身由 `PlainDate` 表达（无时区日期值类型，兼容 API 14），时区只在 `CalendarClock` 里出现一次。
