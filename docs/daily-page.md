# 页面版式与数据来源

「今朝 · 每日一页」是应用唯一的内置版式，全部由 `DailyPage` 用 Canvas 绘制，没有任何图片资源。

## 设计坐标

| 方向 | 设计尺寸 | 版式 |
| --- | --- | --- |
| 竖屏 | 360 × 600 | 单列：日期行 / 时钟 / 月历 / 宜忌（左下） |
| 横屏 | 640 × 360 | 通栏日期行 / 左列时钟与宜忌 / 右列月历 |

所有坐标都是设计坐标，`PaperView` 按 `unit = 实际尺寸 / 设计尺寸` 缩放后在真实像素上绘制，所以同一套常量在小屏和大屏上比例一致。

## 版式规则

- **贴边**：整页 `EDGE = 14`，只有旧模板的一半左右，省下的空间全部给字号。
- **全部加粗**：日期行、时钟、月历数字与农历、宜忌条目一律粗体；只保留笔画本身的粗细对比（衬线用于中文，无衬线用于数字与时钟）。
- **日期行**：`11月` 20 号 + 日号 46 号 + `日` 20 号 + `星期六` 18 号，右侧以同一条基线右对齐当天农历（16 号）。日号刻意比前后文字更大更重。整行宽度会先量一遍，放不下时按比例收缩（最低 55%），保证不压到右侧的农历。
- **时钟**：竖屏 64 号、横屏按左列宽度自动放大（上限约 1.5 倍），字距 1。
- **横屏通栏**：日期行与分隔线贯穿整个屏幕宽度，月历不再与时钟齐平，而是排在通栏线下方、贴住屏幕下沿，视觉上整体下移。
- **月历**：固定六行七列，周一在前、周日在后。日号占格高的 62%，农历标签另占 30%；周末日号用红色，今天实心底圆反白，非本月日期降到 26% 不透明度。农历一律纯黑，节气与节日由同一标签轮播呈现。
- **宜 / 忌**：整块贴在屏幕左下角。「宜」是绿色圆角块内白色「宜」字，条目用绿色；「忌」是红色圆角块内白色「忌」字，条目用红色。条目按全角空格分隔自动换行，某一侧没有条目时印「诸事不宜」或「诸事皆宜」。

## 字号调节

样式面板的「字号」滑块把整页按 **85% – 140%** 缩放，默认 100%。缩放不是简单乘系数，`DailyPage` 会先按目标字号算一遍版式，不满足下面任一条就按 2% 递减重算，直到满足或触底（70%）：

| 保护条件 | 含义 |
| --- | --- |
| 日期行 `headerFit` | 整行宽度 + 农历宽度 ≤ 版心宽度 |
| 月历 `cellH ≥ 26` | 六行格子不会被压成一条 |
| 宜忌 `almanacY ≥ 时钟底 + 6` | 宜忌块不会顶到时钟 |
| 月历数字 `fitNumber` | 数字宽度 ≤ 格宽 92%，高度 ≤ 标签以上剩余高度 |
| 农历标签 `min(cellH × 30%, cellW × 46%)` | 两个字一定落在格内 |
| 宜忌占比上限 | 竖屏 ≤ 页高 26%、横屏 ≤ 46%，超出时只缩宜忌条目，不牺牲月历 |

因此滑块拉到两端也只会出现“月历略紧、宜忌略小”，不会重叠、覆盖、裁切或超出屏幕。设备验收在 85% / 100% / 140% 三种字号、横竖两个方向下逐张贴图渲染，并检查屏幕最底三行像素必须仍是纸色。

## 轮播时间轴

带节气或节日的日期，其标签在农历与节日名之间循环上滑：

| 常量 | 值 | 含义 |
| --- | --- | --- |
| `HOLD_MS` | 3000 | 每个字段的静止停留时间 |
| `TRANSITION_MS` | 240 | 上滑过渡时长 |
| `CYCLE_MS` | 3240 | 一轮的完整周期 |

相位取自 `SystemClock.uptimeMillis()`，全页共用一个时间轴，因此同一行的所有单元格同时翻页。过渡时旧文字自 `y` 上移到 `y - h`，新文字同步自 `y + h` 上移到 `y`。

`DailyPage.frameDelay(now)` 给出下一次画面可能变化的时间：停留期取相位剩余时间，过渡期取一帧（16 ms）。`PaperView` 再与“下一个整分钟”（时钟）取最小值调度重绘，因此停留期几乎不重绘。

静态场景（预览卡片、验收渲染）把 `motion` 置为 `false`、`now` 置为 `0`，直接印出第一个字段；动画偏好为 0 时同样走这条路径。

## 数据来源

历法与宜忌由 `tyme4j`（`com.tyme.solar.SolarDay`）计算，全部在本地完成：

| 需求 | 取值 |
| --- | --- |
| 农历月名 / 日名 | `lunarDay.lunarMonth.name`、`lunarDay.name` |
| 节气 | `termDay`，仅当 `dayIndex == 0` 才算当天 |
| 农历节日、公历节日 | `lunarDay.festival`、`festival` |
| 数九、三伏 | `nineDay`、`dogDay`，同样只取 `dayIndex == 0` |
| 宜、忌 | `lunarDay.recommends`、`lunarDay.avoids` |

节气只在节气当天标注；同一天的多个节日（例如中秋与国庆）全部保留并按顺序轮播。

## 缓存与刷新

- **按日缓存 8 条** `CalendarData`：旋转屏幕、切后台回来、恢复前台都直接命中。
- **按月缓存 4 份月历网格**：跨午夜时只换当天数据，六行七列的 42 格复用上一次的结果。
- **整分对齐**：`PaperView` 用 `System.currentTimeMillis() % 60_000` 安排下一次重绘，时钟跳分钟、跨过午夜换日都不依赖轮询。

日期本身由 `PlainDate` 表达（无时区日期值类型，兼容 API 14），时区只在 `CalendarClock` 里出现一次。
