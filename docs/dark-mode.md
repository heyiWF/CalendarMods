# 深色模式

同一页日历有两种印法：**纸张黄**与**深色纸**。两者共用同一套版式与同一份历法数据，只是把配色换成另一组 token，因此渲染代码只有一套。

## 四种来源

样式面板的「深色模式」是一组单选，修改即时生效并写入 `theme_styles`：

| 选项 | 行为 |
| --- | --- |
| 关闭 | 始终使用浅色页（默认） |
| 始终深色 | 忽略时间与环境光，始终使用深色页 |
| 定时切换 | 本地时间落在夜间窗口内时使用深色页 |
| 跟随环境光 | 环境变暗时切到深色，变亮时切回浅色；设备带光线传感器时出现这一项 |

**夜间窗口**默认为 `19:00 – 07:00`，可以在选中「定时切换」后拖动「深色开始」「深色结束」两条滑块逐小时调整。窗口允许跨过午夜（例如 `22:00 – 06:00`）；两个时间相同时窗口为空，页面保持浅色，便于临时关闭定时。

## 光线阈值

`LuxDarkGate` 负责把照度读数变成「房间够暗」的判断：

| 条件 | 结果 |
| --- | --- |
| 照度 ≤ 12 lx | 候选深色 |
| 照度 ≥ 45 lx | 候选浅色 |
| 12 – 45 lx 之间 | 维持当前印法（迟滞区间，避免黄昏时反复翻转） |
| 候选状态持续 1.2 秒 | 真正切换 |

确认窗口之外的抖动（有人经过、云影、屏幕反光）由迟滞区间吸收，页面保持当前印法。传感器只在前台注册（`onResume` – `onPause`），采样率为 `SENSOR_DELAY_NORMAL`；同一个来源还会每 600 ms 复查一次已收到的读数，让确认窗口到期后能落地。

## 定时检查

定时模式按本地整分钟对齐检查一次（`60_000 - 当前毫秒 % 60_000`），跨时区或手动改时间都会读到新的本地小时，不需要额外的广播接收器。

## 切换链路

```
样式面板 → ThemeStyle.darkMode
        → DarkModeController.resolve() → onChanged(dark)
        → MainActivity.applyDark()
             ├─ 窗口底色 = scheme.backdrop
             ├─ 状态栏图标：浅色页用深色图标（API 23+）
             ├─ 预览页重绘（PreviewCache 的 key 含 dark 位）
             └─ 全屏页原地重绘，不播放翻页动画
```

预览缓存键包含当前印法，因此深色与浅色预览各存一份，来回切换不需要重新排版。

## 配色 token

| Token | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `backdrop` | `#DDC79C` | `#0E0D0A` | 预览页底、窗口底色 |
| `paper` | `#F7EBCE` | `#1B1913` | 纸面 |
| `chrome` | `#443B2B` | `#C8BCA0` | 预览页文字 |
| `ink` | `#14110C` | `#F3EAD4` | 正文、月历数字与农历 |
| `accent` | `#B3362B` | `#E1715C` | 忌、周末日号 |
| `herb` | `#2E6F3E` | `#7CC08D` | 宜 |
| `onAccent` | `#F7EBCE` | `#14120C` | 色块内的「宜」「忌」 |

深色页的色块是浅色填充 + 深色字（绿色 `#7CC08D` 上印深色「宜」），在暗色纸面上对比度更高；浅色页仍是绿色填充 + 米白字。单元测试对两套配色分别校验正文对比度 ≥ 7:1、宜忌与色块文字 ≥ 3:1。

## 兼容性

主题切换只用到 `SharedPreferences`、`SensorManager` 与 `Canvas`，API 14 起可用。`SYSTEM_UI_FLAG_LIGHT_STATUS_BAR` 仅在 API 23 及以上写入，旧系统保持系统默认的状态栏样式。
