# CalendarMods

<img src="docs/media/app-icon-playstore.png" width="112" alt="CalendarMods：深蓝金属质感与珊瑚橙日历图标">

**把一页喜欢的日历，留在屏幕上。**

CalendarMods 是一款专注于日历展示的 Android 应用。整页只保留一种版式：**今朝 · 每日一页**——护眼的纸张黄背景、粗体大号的日期行、一只安静的时钟、当天的宜与忌，以及一张周一开头的月历。轻点进入全屏，让手机或平板成为一页随时间更新的日历。

**单一版式 · 六十格月历 · 农历与节气轮播 · 字号滑块 · 深浅两套纸 · 沉浸全屏 · 午夜翻页 · 离线使用**

支持 **Android 4.0（API 14）及以上**。界面由系统 View 与 Canvas 绘制，不依赖 Jetpack Compose，也不使用 `java.time` 或图片资源。

## 一页纸上的月历

月历固定为六行七列，**周一在前、周日在后**，所以每个月都是完整的六十格，不会因为月初落在周中而跳动位置。

- **每格两行**：上方是当天的日号，下方是当天的农历，都用粗体印出，尽量占满格子的可用高度。
- **周末红字**：周六、周日的日号用红色印出，一眼看得见休息日；农历保持纯黑，保持整齐。
- **今天实心圆**：今日的日号反白印在黑底实心圆上，翻到别的日期时圆点跟着移动。
- **非本月淡出**：月初月末补位的日期降到 26% 不透明度，保留上下文但不抢视线。

当某天有节气或节日时，下方那一行会在**农历、节气、节日之间轮播**：每项停留 **3 秒**，过渡时旧文字向上滑出、新文字自下而上滑入，整页所有格子共用同一条时间轴，所以一行里的日期同时翻页，不会各说各话。清明节气的判定只落在节气当天，节日的多个名称会一并保留。

## 日期行与时钟

日期行写成一串“**11月 6 日 星期五**”：月份、星期与“日”字都是粗体，**当天的日号再放大一号**，视线第一眼落在这里。右侧对齐当天的农历（如“九月廿八”），与本行同一条基线；整行放不下时会按比例收缩，不会压到农历。

- **边距收到 14**，元素贴近屏幕边缘，省下来的空间全部给字号。
- **横屏通栏**：日期行与下方分隔线贯穿整个屏幕宽度，月历排在通栏线下方并贴住屏幕下沿，整体向下移动。
- 时钟使用粗体数字，竖屏 64 号，横屏按左列宽度自动放大。
- **宜、忌在左下角**：绿色圆角块里一个白色「宜」字，条目用绿色；红色圆角块里一个白色「忌」字，条目用红色。条目自动换行，某一侧没有条目时印“诸事不宜”或“诸事皆宜”。

## 轻点展开，专注于眼前这一页

单击日历，它会从预览平滑展开到全屏，隐藏状态栏与导航栏。长按或使用系统返回键，日历便缩回原来的位置。沉浸显示时屏幕保持常亮；返回预览后恢复正常熄屏。横竖屏都有对应版式：竖屏是一张完整的纸页，横屏左列是日期、时钟与宜忌，右列是月历。

## 样式设置

右上角的样式按钮提供一条字号滑块、一组深色模式与三个开关，修改即时生效并自动保存：

- **字号**：85% – 140% 连续可调，默认 100%。整页等比缩放，同时逐块校验：日期行不会压到农历，月历格子不会被压扁，宜忌块不会顶到时钟，宜忌最多只占页面的一角。即使拉到两端也不会出现重叠、覆盖、裁切或超出屏幕。
- **深色模式**：默认关闭。可以选「始终深色」直接换成深色纸；也可以「定时切换」，在设定的夜间窗口内（默认 19:00 – 07:00，可跨午夜、可逐小时调整）自动换页；设备带光线传感器时还能「跟随环境光」，环境变暗时切深色、变亮时切回浅色。手动切换只换配色，不重新排版，也不会丢字或裁切。
- **翻页动画**：默认开启，跨过午夜时以 3D 翻页迎接新的一天；关闭后日期直接切换。
- **人脸感应亮屏**：默认关闭。开启并授权摄像头后，全屏时会根据画面判断有没有人在看，有人靠近自动点亮，离开一段时间后允许熄屏。图像只在内存中处理，不保存、不上传，应用不需要联网权限。
- **交互式日历**：默认关闭。开启后可在全屏左右滑动浏览其他日期，离开今天时底部浮现“回到今天”。

## 开始使用

1. **点击样式按钮**，拖动字号滑块、挑选深色模式，或按需打开翻页动画、人脸感应亮屏与交互式日历。
2. **单击日历**，进入沉浸全屏。
3. **长按界面或按返回键**，回到预览页。
