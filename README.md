# CalendarMods

<img src="docs/media/app-icon-playstore.png" width="112" alt="CalendarMods：深蓝金属质感与珊瑚橙日历图标">

**把一页喜欢的日历，留在屏幕上。**

CalendarMods 是一款专注于日历展示的 Android 应用。整页只保留一种版式：**今朝 · 每日一页**——纸色背景、大号日期、一只安静的时钟、当天的宜与忌，以及一张周一开头的月历。轻点进入全屏，让手机或平板成为一页随时间更新的日历。

**单一版式 · 六十格月历 · 农历与节气轮播 · 沉浸全屏 · 午夜翻页 · 离线使用**

支持 **Android 4.0（API 14）及以上**。界面由系统 View 与 Canvas 绘制，不依赖 Jetpack Compose，也不使用 `java.time` 或图片资源。

## 一页纸上的月历

月历固定为六行七列，**周一在前、周日在后**，所以每个月都是完整的六十格，不会因为月初落在周中而跳动位置。

- **每格两行**：上方是当天的日号，下方是当天的农历。
- **周末红字**：周六、周日的日号与农历都用红色印出，一眼看得见休息日。
- **今天实心圆**：今日的日号反白印在实心底圆上，翻到别的日期时圆点跟着移动。
- **非本月淡出**：月初月末补位的日期用浅灰印出，保留上下文但不抢视线。

当某天有节气或节日时，下方那一行会在**农历、节气、节日之间轮播**：每项停留 **3 秒**，过渡时旧文字向上滑出、新文字自下而上滑入，整页所有格子共用同一条时间轴，所以一行里的日期同时翻页，不会各说各话。清明节气的判定只落在节气当天，节日的多个名称会一并保留。

## 日期行与时钟

日期行写成一串“**11月 6 日 星期五**”：月份、星期与“日”字用衬线常规字重，**当天的日号单独放大并加粗**，视线第一眼落在这里。右侧对齐当天的农历（如“九月廿八”），与本行同一条基线。

- 所有文字块共用一条左边线与一条右边线，日期、时钟、宜忌、月历逐块对齐。
- 时钟使用细字重的 64 号数字，字距略微放宽，紧贴分隔线下方。
- 宜、忌两块按当天条数自动换行，并按剩余高度平均分配间距；某一侧没有条目时印“诸事不宜”或“诸事皆宜”，不留空洞。

## 轻点展开，专注于眼前这一页

单击日历，它会从预览平滑展开到全屏，隐藏状态栏与导航栏。长按或使用系统返回键，日历便缩回原来的位置。沉浸显示时屏幕保持常亮；返回预览后恢复正常熄屏。横竖屏都有对应版式：竖屏是一张完整的纸页，横屏左列是日期、时钟与宜忌，右列是月历。

## 样式设置

右上角的样式按钮提供三个开关，修改即时生效并自动保存：

- **翻页动画**：默认开启，跨过午夜时以 3D 翻页迎接新的一天；关闭后日期直接切换。
- **人脸感应亮屏**：默认关闭。开启并授权摄像头后，全屏时会根据画面判断有没有人在看，有人靠近自动点亮，离开一段时间后允许熄屏。图像只在内存中处理，不保存、不上传，应用不需要联网权限。
- **交互式日历**：默认关闭。开启后可在全屏左右滑动浏览其他日期，离开今天时底部浮现“回到今天”。

## 开始使用

1. **点击样式按钮**，按需打开翻页动画、人脸感应亮屏或交互式日历。
2. **单击日历**，进入沉浸全屏。
3. **长按界面或按返回键**，回到预览页。

日期、农历、节气与宜忌全部离线计算，随设备日期与时区更新；前台全屏跨过午夜会自动进入新的一天，从后台回来时直接同步。
